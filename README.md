# Shoelace Grid System

A lightweight, performant 2D grid system for Unity with chunking support and spatial query tools.

## Requirements

- Unity 2021.3 or higher
- [Shoelace Utilities Package](https://github.com/Ryan-Pierce-Shoelace/Shoelace-Utilities)

# Installation

1. Install required Shoelace Utilities package via Package Manager (Git
   URL): `https://github.com/Ryan-Pierce-Shoelace/Shoelace-Utilities.
2. Add this package via Package Manager using: `https://github.com/Ryan-Pierce-Shoelace/Shoelace-Grid-System`
